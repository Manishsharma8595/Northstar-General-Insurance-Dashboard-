# Northstar General Insurance – Power BI Dashboard

An interactive **insurance analytics dashboard** built using **SQL and Power BI** to analyze customer demographics, policy performance, premium amounts, and claim trends.

### 📊 Key Insights

* Analyzed customer distribution by **gender and age group**
* Compared **premium amounts across different policy types**
* Analyzed **active vs. inactive customers**
* Tracked **claim volumes by claim status**
* Compared **claim amounts across different age groups**
* Analyzed **pending, rejected, and settled claims** by policy type
* Added interactive filters for **Policy Number, Claim Number, and Customer ID**

### 🛠️ Tools Used

* **SQL** – Data querying and preparation
* **Power BI** – Data visualization and interactive dashboard development

### 🎯 Objective

The objective of this project is to demonstrate the use of **SQL for data analysis and Power BI for transforming insurance data into an interactive business intelligence dashboard**, enabling users to identify key trends in customers, policies, premiums, and claims.
